# A Protein Molecule in a Mixed Solvent: The Preferential Binding Parameter via the Kirkwood-Buff Theory

PII: `S0006349506722494`
DOI: `10.1529/biophysj.105.074112`

## Article Body

In a recent article (Schurr, J. M., D. P. Rangel, and S. R. Aragon. 2005. A contribution to the theory of preferential interaction coefficients. Biophys. J . 89:2258–2276), a detailed derivation of an expression for the preferential binding coefficient via the Kirkwood-Buff theory of solutions was presented. The authors of this Comment (Shulgin, I. L., and E. Ruckenstein. 2005. A protein molecule in an aqueous mixed solvent: fluctuation theory outlook. J. Chem. Phys . 123:054909) also recently established on the basis of the Kirkwood-Buff theory of solutions an equation for the preferential binding of a cosolvent to a protein. There are other publications that relate the preferential binding parameter to the Kirkwood-Buff theory of solutions for protein + binary mixed solvents. The expressions derived in the two articles mentioned above are different because the definitions of the preferential binding parameter are different. However, there are articles in which the definitions of the preferential binding parameter are the same, but the derived equations that relate the preferential binding parameter to the Kirkwood-Buff integrals are different. The goal of this Comment is to examine the various expressions that relate the preferential binding parameter to the Kirkwood-Buff theory.
We are indebted to Prof. J. Michael Schurr (Dept. of Chemistry, University of Washington, Seattle, WA) for helpful comments regarding this manuscript and for drawing our attention to the fact that the coefficients Γ 3 ( 2 ) and Γ 23 ( c ) are different.

## Introduction

An important characteristic of a solution of a protein (component 2) in a mixture water (1) + cosolvent (3) is the preferential binding parameter Γ 23 ( m ) (1–6) (1) Γ 23 ( m ) ≡ lim m 2 → 0 ( ∂ m 3 / ∂ m 2 ) T , P , μ 3 , where m i is the molality of component i, P is the pressure, T is the absolute temperature, and μ i is the chemical potential of component i. The preferential binding parameter can be also defined at a molarity scale by (2) Γ 23 ( c ) ≡ lim c 2 → 0 ( ∂ c 3 / ∂ c 2 ) T , P , μ 3 , where c i is the molar concentration of component i. It should be emphasized that Γ 23 ( m ) and Γ 23 ( c ) are defined at infinite protein dilution.

The preferential binding parameter Γ 23 ( m ) was determined experimentally (5–7) and provides information regarding the interactions between a protein and the components of the mixed solvent. As a rule (1–5) , Γ 23 ( m ) < 0 , the protein is preferentially hydrated, for cosolvents such as glycerol, sucrose, etc., which can stabilize at high concentrations the protein structure and preserve its enzymatic activity (3–5) , and Γ 23 ( m ) > 0 , the protein is preferentially solvated by cosolvents (such as urea), which can cause protein denaturation.

In literature (8) a number of different definitions of the preferential binding parameter (coefficient) have been employed. They can be connected by thermodynamic relations for ternary mixtures (8) . In this Comment the preferential binding parameter will be mostly defined by Eqs. 1 and 2 .

Because the preferential binding parameter is a meaningful physical quantity, attempts have been made to relate it to a general theory of solutions, such as the Kirkwood-Buff theory of solutions (9) . Several authors reported results in this direction (10–17) . The authors of this Comment derived the following equation for Γ 23 ( c ) (16) : (3) Γ 23 ( c ) = c 3 ( G 23 − G 13 ) , where G 13 and G 23 are the Kirkwood-Buff integrals defined as (9) (4) G α β = ∫ 0 ∞ ( g α β − 1 ) 4 π r 2 d r , where g α β is the radial distribution function between species α and β , and r is the distance between the centers of molecules α and β .

Equation 3 differs from the expression of Γ 23 ( c ) employed in Shimizu (10,11) : (5) Γ 23 ( c ) = c 3 ( G 23 − G 12 ) .

In a recent article in this journal (17) , the Kirkwood-Buff theory of solutions was used to express the preferential binding coefficient Γ 3 ( 2 ) , defined as (6) Γ 3 ( 2 ) ≡ − lim c 2 → 0 ( ∂ μ 2 / ∂ μ 3 ) T , P , c 2 , in terms of the Kirkwood-Buff integrals. It was found (17) that (7) Γ 3 ( 2 ) = c 3 ( G 23 − G 12 ) .

As noted in Schurr et al. (17) the preferential binding coefficient Γ 3 ( 2 ) defined by Eq. 6 differs from the preferential binding parameter Γ 23 ( c ) defined by Eq. 2 .

However, Eqs. 3 and 5 are different equations even though they are based on the same definition of the preferential binding parameter and have the same theoretical basis: the Kirkwood-Buff theory of solutions. To make a selection between Eqs. 3 and 5 a simple limiting case, the ideal ternary mixture, will be examined using the traditional thermodynamics, and the results will be compared to those provided by Eqs. 3 and 5 .

## Ideal ternary mixture

Let us consider an ideal ternary mixture. According to the definition of an ideal mixture (18) , the activities of the components ( a i ) are equal to their mol fractions ( x i ) and their partial molar volumes are equal to those of the pure components ( V i = V i 0 ).

Because (8) d μ 3 = ∂ μ 3 ∂ T P , c 2 , c 3 d T + ∂ μ 3 ∂ P T , c 2 , c 3 d P + ∂ μ 3 ∂ c 2 T , P , c 3 d c 2 + ∂ μ 3 ∂ c 3 T , ⁡ P , ⁡ c 2 d c 3 , one can write for an ideal mixture (9) Γ 23 ( c ) ≡ lim c 2 → 0 ( ∂ c 3 / ∂ c 2 ) T , P , μ 3 = − lim c 2 → 0 ∂ μ 3 ∂ c 2 T , P , c 3 ∂ μ 3 ∂ c 3 T , P , c 2 = − lim c 2 → 0 ∂ ln x 3 ∂ c 2 T , P , c 3 ∂ ln x 3 ∂ c 3 T , P , c 2 .

For isothermal-isobaric conditions (10) d c 2 = d x 2 V − x 2 V 2 ∂ V ∂ x 2 x 3 d x 2 + ∂ V ∂ x 3 x 2 d x 3 , and (11) d c 3 = d x 3 V − x 3 V 2 ∂ V ∂ x 2 x 3 d x 2 + ∂ V ∂ x 3 x 2 d x 3 , where V is the molar volume of the ternary mixture.

When c 3 is a constant, Eqs. 10 and 11 lead to (12) ∂ c 2 ∂ x 3 c 3 = V − x 2 ∂ V ∂ x 2 x 3 − x 3 ∂ V ∂ x 3 x 2 x 3 V ∂ V ∂ x 2 x 3 , and when c 2 is a constant, Eqs. 10 and 11 lead to (13) ∂ c 3 ∂ x 3 c 2 = V − x 2 ∂ V ∂ x 2 x 3 − x 3 ∂ V ∂ x 3 x 2 V V − x 2 ∂ V ∂ x 2 x 3 .

By inserting Eqs. 12 and 13 into Eq. 9 at infinite dilution of component 2, one obtains the following expression for Γ 23 ( c ) of an ideal ternary mixture: (14) Γ 23 ( c ) ( i d e a l ) = c 3 ( V 1 0 − V 2 0 ) .

On the other hand, expressions for Γ 23 ( c ) for an ideal ternary solution can be also derived by combining Eq. 3 or Eq. 5 with the following Kirkwood-Buff integrals for ideal ternary mixtures (16) : (15) G 12 ( id ) = k T k T ( id ) − V 3 0 c 3 ( V 1 0 − V 3 0 ) − V 2 0 (16) G 23 ( id ) = k T k T ( id ) + V 1 0 c 1 ( V 1 0 − V 3 0 ) − V 2 0 (17) G 13 ( id ) = k T k T ( id ) − ( c 1 + c 3 ) V 1 0 V 3 0 , where k is the Boltzmann constant and k T is the isothermal compressibility.

Equation 3 leads to (18) Γ 23 ( c ) ( i d e a l ) = c 3 ( V 1 0 − V 2 0 ) , whereas Eq. 5 to (19) Γ 23 ( c ) ( i d e a l ) = c 3 ( V 1 0 − V 3 0 ) .

## Discussion

One can see that the result obtained on the basis of Eq. 3 (Eq. 18 ) coincides with Eq. 14 derived from general thermodynamic considerations, whereas that based on Eq. 5 does not. The numerical difference between the two expressions is very large because the molar volume of a protein is, usually, much larger than the molar volume of the cosolvent.

Whereas the above discussion involves Γ 23 ( c ) , the quantity Γ 23 ( m ) , which is usually determined experimentally (2–7) , is related to Γ 23 ( c ) through the equation (1,16) (20) Γ 23 ( c ) = ( 1 − c 3 V 3 ) Γ 23 ( m ) − c 3 V 2 ∞ , where V 2 ∞ is the partial molar volume of the protein at infinite dilution. V 2 ∞ and V 3 can be expressed at infinite dilution of component 2 in terms of the Kirkwood-Buff integrals as follows (19) : (21) V 2 ∞ = 1 + c 1 ( G 11 − G 12 ) + c 3 ( G 33 − G 23 ) + c 1 c 3 ( − G 12 G 33 + G 12 G 13 − G 13 2 + G 13 G 23 + G 11 G 33 − G 11 G 23 ) c 1 + c 3 + c 1 c 3 ( G 11 + G 33 − 2 G 13 ) , and (9) (22) V 3 = 1 + ( G 11 − G 13 ) c 1 c 1 + c 3 + c 1 c 3 ( G 11 + G 33 − 2 G 13 ) .

By combining Eqs. 3, 20, 21, and 22 , one obtains after some algebra the following simple expression: (23) Γ 23 ( m ) = c 3 c 1 + c 3 ( G 23 − G 12 + G 11 − G 13 ) .

Whereas G 12 and G 23 depend on the protein characteristics, G 11 and G 13 depend only on the characteristics of the protein-free mixed solvent.

For usual cosolvents (organic solvents, salts, etc.), one can use the following approximation of Eq. 23 in the dilute cosolvent range: (24) Γ 23 ( m ) ≈ c 3 ( G 23 − G 12 ) .

Indeed, | G 11 | and | G 13 | are much smaller than the Kirkwood-Buff integrals for the pairs involving the protein ( | G 12 | and | G 23 | ). Table 1 provides their values for the system water (1) + lysozyme (2) + urea (3) (pH 7.0, 20°C).

However, when | G 11 | and | G 13 | are large, and this occurs when the cosolvent is, for example, a polymer ( G 13 ≈ − 1000 (cm 3 /mol) for the system water/polyethylene glycol 2000 at a weight fraction of polyethylene glycol of 0.02 (21) ), the complete Eq. 23 should be used. This conclusion is valid for all large cosolvent molecules (polymers, biomolecules, etc.).

Let us consider the biochemical equilibrium between infinitely dilute native ( N ) and denaturated ( D ) states of a protein in a mixed solvent. The changes of the preferential binding parameters Γ 23 ( c ) , ⁡ Γ 23 ( m ) , and Γ 3 ( 2 ) in this process are given by (25) Δ Γ 23 ( c ) = c 3 ( G 23 ( D ) − G 23 ( N ) ) = c 3 Δ G 23 (26) Δ Γ 23 ( m ) = c 3 ( G 23 ( D ) − G 23 ( N ) − G 12 ( D ) + G 12 ( N ) ) = c 3 ( Δ G 23 − Δ G 12 ) , and (27) Δ Γ 3 ( 2 ) = c 3 ( G 23 ( D ) − G 23 ( N ) − G 12 ( D ) + G 12 ( N ) ) = c 3 ( Δ G 23 − Δ G 12 ) = Δ Γ 23 ( m ) .

Equations 25 and 26 follow from Eqs. 3 and 23 by taking into account that G 11 and G 13 are characteristics of the protein-free mixed solvent at infinite protein dilution.

The equilibrium constant K of biochemical equilibrium between infinitely dilute native ( N ) and denaturated ( D ) states of a protein in a mixed solvent can be expressed in terms of Δ Γ 23 ( m ) (22) (28) ∂ ln K ∂ ln a 3 T , P , m 2 = ∂ μ 3 ∂ m 2 T , P , m 3 N − ∂ μ 3 ∂ m 2 T , P , m 3 D ∂ μ 3 ∂ m 3 T , P , m 2 = Δ Γ 23 ( m ) , where Δ Γ 23 ( m ) can be provided by experiment (23) .

Using for G 12 and G 23 expressions from Shulgin and Ruckenstein (16) , Eq. 28 can be also rewritten in the form (29) ∂ ⁡ ln ⁡ K ∂ ⁡ ln ⁡ a 3 T , ⁡ P , ⁡ m 2 = c 3 Δ J 21 c 1 + c 1 J 11 + c 3 , where J 11 = li m x 2 → 0 ( ∂ ⁡ ln ⁡ γ 1 / ∂ x 1 ) x 2 , J 21 = li m x 2 → 0 ( ∂ ⁡ ln ⁡ γ 2 / ∂ x 1 ) x 2 , and γ i is the activity coefficient of component i at a mol fraction scale.
