## Abstract or detected summary

Sensors and smart equipment are frequently used in biomechanical systems and applications in sports and rehabilitation to measure various physical quantities. Various sensors, measuring different parameters, can produce a large amount of data at high speeds and volumes that must be stored for real-time or post-processing and analysis. In addition to sensor data, metadata is an important component and can vary between biomechanical applications. Currently however, each application typically has its own unique data flow and storage solution. In this research, we present a universal data model solution that can be applied to any sensor-based biomechanical application in sport and physical rehabilitation.
